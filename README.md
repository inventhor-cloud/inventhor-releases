# INVENTHOR Releases

This repository is the public, release-only download channel for the verified INVENTHOR **user application** and user-installable modules.

## Download

No stable public build has been released yet.

When the release gates pass, the latest verified packages will be available at:

https://github.com/inventhor-cloud/inventhor-releases/releases/latest

## Safety

- Development and debug-signed APKs are not published here.
- Every release includes platform, version, SHA-256, signature identity, compatibility, test evidence, and rollback information.
- Source repositories, private Brain instances, user data, tokens, secrets, keystores, and private logs are not stored here.
- Install only artifacts whose hash matches the signed release manifest.

## Planned packages

- INVENTHOR user application
- INVENTHOR Operator
- Native Runtime Worker
- Local, hybrid, and cloud connectors
- Signed module and firmware packages

The private Mimar/Owner application is a different product with a different package identity, signing identity, permission policy, and private release channel. Owner artifacts are never published in this repository.
